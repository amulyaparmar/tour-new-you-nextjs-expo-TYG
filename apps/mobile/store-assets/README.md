# Tour Store Assets

## Recommended Store-Ready Set

Use `store-ready-v4/` for submission. This version uses a slimmer hardware-accurate iPhone display, Tour's native light palette, the same iOS system font used by the app, and seven individual feature captions:

1. Every tour, all in one place.
2. Start in seconds.
3. Practice before the real tour.
4. Capture every conversation.
5. Know exactly what to improve.
6. Guidance when you need it.
7. Turn insight into action.

Upload Apple files from `store-ready-v4/apple/iphone-6.9/`. The matching Google images are in `store-ready-v4/google/phone-screenshots/` and use neutral Android system chrome. Use `store-ready-v4/google/feature-graphic.png` as the Google Play feature graphic.

Run `node apps/mobile/store-assets/generate-store-ready-v4.mjs` from the repository root to rebuild the set from the latest source captures.

## Recommended Individual Set

The earlier `single-screen-light/` campaign is retained as a simpler alternate. Each image focuses on one authentic Tour screen with its own caption:

1. See every tour at a glance.
2. Start a tour in seconds.
3. Capture every conversation.
4. Get guidance in the moment.
5. Turn insight into action.

Upload the Apple files from `single-screen-light/apple/iphone-6.9/` and the Google files from `single-screen-light/google/phone-screenshots/` in numeric order.

## Multi-Screen Alternative

The `connected-light/` campaign uses Tour's native light palette with multiple screens in each image:

1. Better tours. More leases.
2. Start in seconds.
3. Capture every word.
4. Ask Tour AI.
5. Know what to improve.
6. Review. Improve. Convert.

## Apple App Store

Upload the six files in `connected-light/apple/iphone-6.9/` in numeric order. Each file is a 1320 x 2868 PNG and combines authentic Tour screens inside the campaign artwork.

## Google Play

Upload the six files in `connected-light/google/phone-screenshots/` in numeric order. These use the same cross-platform Tour views with neutral Android system chrome. Use `connected-light/google/feature-graphic.png` as the Google Play feature graphic.

The earlier dark campaign remains in `apple-app-store/` and `google-play/` for reference, but it is not the recommended submission set.

## Source Screens

`source/ios/` contains the original simulator captures used in the campaign. These are retained so the marketing screenshots can be updated when the product UI changes.
